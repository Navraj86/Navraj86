### About me

I'm a backend-focused full-stack engineer working mainly in **Node.js, TypeScript and React**, building APIs, authentication, databases and deployment.

For over a year I worked on **gammon.gg**, the tournament platform for the Backgammon World Championship, on a remote contract. I moved authentication to a dedicated identity server with role-based access across services, built the tournament APIs and data model, set up the CI/CD pipeline and centralized logging, and built the web and mobile apps players used to follow live tournaments, plus the admin panel organizers used to run them.

Before that, I built a property and lease management platform for the **Red Cross Society, Bathinda**, under the Deputy Commissioner's office, end to end from design to launch.
